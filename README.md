# RSS Tracker Service

Мониторинг новостей по ключевым словам из RSS-лент с веб-интерфейсом управления

## Особенности
- Отслеживание ключевых слов в RSS-лентах
- Веб-интерфейс для управления и просмотра результатов
- Логирование всех найденных новостей
- SQLite база данных для хранения данных
- REST API для интеграции
